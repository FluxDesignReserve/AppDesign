# examples/

`starter.html` — a working page skeleton built **only** from `../reference/tokens.css`:
header with current-page underline, hero with accented headline clause, split
copy/terminal panel, card grid, benchmark table with a highlighted winning row, and
footer. Every value is a token; nothing is hardcoded.

`starter-1440-fold.png` — that file rendered at 1440×900. Put it next to
`../Tensorlake/fold/home-1440-fold.png`: same darkness, same ruled structure, same
type rhythm. That comparison is how you check the system is being applied rather than
approximated.

Copy `starter.html` and replace the content when starting new page work. It loads
Inter Tight and JetBrains Mono from Google Fonts as the licence-free stand-in for
PP Neue Montreal — swap in the real face where it is licensed.
