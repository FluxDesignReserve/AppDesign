Is LambdaTest still available?

Yes. LambdaTest is now TestMu AI. Every product, feature, integration and piece of infrastructure is available under the new brand at testmuai.com. Existing customers experienced no service interruption, and previously published documentation, learning content and community resources remain accessible.

Do my credentials and API keys still work?

Yes. Accounts, test history, integrations, billing, API keys and team settings transferred automatically. Log in with your existing email and password — no migration, password reset or re-onboarding is required.

Will my CI pipelines keep running?

Yes. All API endpoints, SDK integrations and CI/CD workflows continue to work without code changes. Existing API keys, webhooks, Selenium and Appium Grid endpoints and 120+ third-party integrations function identically.

What is actually different, then?

What was added. On top of cross-browser testing, the real device cloud and automation testing, TestMu AI introduces a full AI-native stack: Kane AI, Kane CLI, agent testing for voice AI and chatbots, AI visual testing and autonomous test orchestration.
